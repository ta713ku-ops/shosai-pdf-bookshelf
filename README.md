# 書斎 — iPad向けPDF本棚PWA

PDFを外部へ送信せず、端末内の本棚に保存して読むWebアプリです。iPadの横向きでは見開き、縦向きでは1ページで表示します。

## 主な機能

- PDFの複数選択、1ページ目からの表紙生成
- IndexedDBへのPDF・表紙・読書位置の端末内保存
- 木製本棚、検索、カテゴリ作成、名称変更、移動、削除
- 右開き／左開き、見開き／1ページ、スワイプ、タップ、ピンチズーム
- PWAインストールと、保存済みPDFのオフライン閲覧
- キーボード操作、44px以上のタッチ領域、Reduce Motion対応

## 起動

```bash
npm install
npm run dev
```

本番確認は `npm run build` の後に `npm run preview` を使います。PWAとして使う場合はHTTPSで配信し、Safariの共有メニューから「ホーム画面に追加」を選びます。

## GitHub Pagesへの公開

GitHubの Settings → Pages → Source を **GitHub Actions** に設定します。`main`へのpushまたは手動実行で、依存導入・テスト・ビルド後に`dist`を公開します。公開パスはPages設定から自動取得するため、リポジトリ名やカスタムドメインにも追従します。

ローカルでプロジェクトサイトを確認する場合は `VITE_BASE_PATH=/repository-name/ npm run build` の後、`npm run preview -- --base=/repository-name/` で配信します。パスの先頭・末尾には `/` を付けてください。Actionsのリポジトリ変数 `VITE_BASE_PATH` で上書きすることもできます（通常は不要です）。

PDFや本棚データは公開物に含まれません。秘密情報をフロントエンドや `VITE_` 環境変数に設定しないでください。

## 保存について

PDFはブラウザのIndexedDBに保存されます。ブラウザの履歴・Webサイトデータを削除すると本棚も消える可能性があります。大切な原本は必ずファイルアプリなど別の場所にも保管してください。

## 現在の範囲

初期版は読書の安定性を優先し、完全な3Dページカール、PDFへの書き込み、クラウド同期、共有メニューから直接受け取る機能は含めていません。
